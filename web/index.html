宗主网页刷机

用 USB 把板子接到电脑，按步骤操作。刷机全程在你的浏览器里完成，Wi-Fi 密码等信息只写进板子，不会上传到任何地方。

小米智能音箱 Pro（OH2P）刷上补丁固件、装上 Client 后，直接连你的宗主后端，就像一块没有屏幕的宗主板子：喊"宗主"，回答从音箱里念出来，小爱同学照常能用。

这个浏览器不支持网页串口。请用电脑上的 Chrome 或 Edge 打开本页（Safari、Firefox 和手机浏览器都不行）。

音箱只负责收音和播放，唤醒词、语音识别、转给 Bot 都在后端做，所以先在一台常开的电脑上装好后端。已经为板子装过的，跳过这步。

        

          
macOS：打开"终端"，粘贴下面这行并回车（和刷板子第 4 步的是同一个脚本）。装好后，脚本最后会显示后端的网关页面地址。

          

            
            
          

        

        
Windows / Linux：用 Docker 运行后端，见 Docker 部署说明；运行 setup 时"接不接小米音箱"选 yes。Docker 里能装 Client，不能刷机：刷机要在 Mac 上用一键安装的后端，或照音箱刷机说明用脚本。

3在网关页面刷补丁固件、装 Client

        
补丁固件在小米官方系统上打开 SSH、设 root 密码、关掉自动升级，开机运行 Client。音箱有 A、B 两套系统，只写一边，另一边的官方系统留着当退路。

        
刷机有变砖的风险，风险自负。只在小米智能音箱 Pro（OH2P）、系统 1.62.2、Apple Silicon 的 Mac 上完整做过。刷机要后端直接运行在 Mac 上（Docker 里摸不到 USB）。

        
    
          
  1. 在网关页面左边点"设备"，找到"给小米音箱刷补丁固件"。音箱用能传数据的 Type-C 线直插电脑。
    2. 
          
  2. 填音箱现在的系统版本（米家 App → 音箱 → 设置 → 检查更新）和要设的 root 密码，点"开始"。后端下载小米的官方包、打补丁做镜像。
    3. 
          
  3. 页面提示后，拔掉音箱电源、等 3 秒再插上。后端自动接住刷机模式，先备份，再写入、逐字节核对。写哪一边默认自动选，也可以自己选 0 号或 1 号（另一边必须是官方系统才会写）。不放心可以先点"只读试一次（不写）"。
    4. 
          
  4. 刷完拔电再插。在下面"接入小米音箱 Pro"里填音箱 IP（路由器管理页面或米家 App 里看）和刚设的 root 密码，点"装到音箱上"。
    5. 
          
  5. 5 步都打勾后几秒，音箱"嘀"一声，就连上了。之后喊"宗主"试试。
    6. 
        

        
root 密码只发给你自己的后端，用一次就丢。电脑的 IP 会写进音箱，最好在路由器上给电脑固定 IP。
          不想用网页的，也可以照 音箱刷机说明 用脚本做，Client 用 安装脚本 装。
