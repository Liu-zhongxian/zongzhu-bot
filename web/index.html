宗主网页刷机

用 USB 把板子接到电脑，按步骤操作。刷机全程在你的浏览器里完成，Wi-Fi 密码等信息只写进板子，不会上传到任何地方。

这个浏览器不支持网页串口。请用电脑上的 Chrome 或 Edge 打开本页（Safari、Firefox 和手机浏览器都不行）。

1连接并识别板子

用能传数据的 USB-C 线连接板子，点下面的按钮，在弹窗里选择板子的串口。

还是连不上：按住板子上的 BOOT 键，拔插一次 USB，松开 BOOT 后再点"连接板子"。

4后端在哪里运行

板子只负责录音和播放，语音识别和转发 Bot 由后端完成。后端需要你自己运行，本页不会把板子连到任何别人的服务器。

第一次用？先在这台电脑上装后端

打开"终端"（启动台搜索"终端"），粘贴下面这行并回车。脚本会安装依赖、下载后端和语音模型（约 200MB，需要几分钟）、询问你的 Bot Webhook 地址，最后显示下面要填的电脑地址，并让你选择启动方式：开机自启（登录后自动在后台运行）或手动启动（需要时自己运行 start.sh，以后也可以再开自启）。

也可以 下载脚本，再在终端运行 bash ~/Downloads/install-mac.sh。重复运行就是更新，已有配置会保留。

一键安装脚本目前只支持 macOS。Windows / Linux 请按 后端安装说明 手动安装。

安装脚本最后会显示这个地址。已经装好的：macOS 终端运行 scutil --get LocalHostName，在结果后面加 .local； Windows / Linux 填电脑的局域网 IP（ipconfig / ip addr），并给电脑设固定 IP。

刷完板子再装、再启动后端也可以。手动安装见 后端安装说明。

部署方法见 服务器部署说明。服务器开启设备白名单后，要把刷完时显示的 MAC 和 client-id 加进去。
