# 验证记录：2.5.2.9

日期：2026-10-18。硬件：Waveshare ESP32-S3-Touch-AMOLED-1.75C。

## 自动检查

- ESP-IDF 6.0.1 构建通过，应用 2,869,392 字节。
- 后端测试 28 项全部通过，新增 3 项覆盖唤醒词误识别：重复唤醒不提交、唤醒词前缀去掉后再提交、普通"你好…"句子不误判。
- 电脑端几何检查：13 种表情 × 3 种布局 × 四角极限视线，各跑 60 秒，眼睛全部在圆屏内，不压字幕，不超出眼睛区域。
- 资源包和 2.5.2.5 字节一致（不含 IKUN）。bootloader、分区表、OTA 初始数据与 2.5.2.3 相同。

## 实机（测试板只写应用 0x20000，哈希校验通过）

- 启动报告 2.5.2.9；触摸、QMI8658（0x6B）、字幕模式读取都正常。
- 5 分钟串口记录：唤醒词识别（置信度 0.27，阈值 0.20）、连接、语音识别、Bot 往返、朗读都正常，没有崩溃和音频告警。
- 对话中又说了一次"你好宗主"，被识别成"你好，宗猪。"，后端记录"忽略重复唤醒词，不提交"。
- 字幕模式长按 BOOT 切换成功，设置重启后仍保留。
- 动画统计（每 30 秒一次）：逻辑帧 35–42 帧/秒；单帧眼睛绘制平均 0.4–0.8ms；内部 RAM 剩余约 118–125KB。说话时最大帧间隔 75–135ms。
- 用户现场反馈：目前没什么问题。
